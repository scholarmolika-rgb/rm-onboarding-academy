# Day 13 — Sanction, documentation and disbursement
- **Sanction letter** records terms and covenants; client accepts in writing.
- **Documentation:** facility agreement, hypothecation/mortgage deeds, guarantees, board resolutions.
- **Security creation:** register charge with ROC; register security interest with **CERSAI within 30 days**.
- **Pre-disbursement conditions** verified by operations (maker-checker) before limits are set up.
