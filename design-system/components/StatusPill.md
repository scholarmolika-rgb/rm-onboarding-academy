# StatusPill

Status pills state where a trainee, escalation or gate stands, using semantic colour only.

Five variants: `good` (Gate cleared, Certified, Low risk), `warn` (Test due at gate, In coaching, Watch), `crit` (Repeating modules, Inactive, High risk, SLA breached), `info` (Test due today, informational), `mute` (Session pending). Always pair colour with a word. Never use a pill as a button. The consumer provides the variant and label.
